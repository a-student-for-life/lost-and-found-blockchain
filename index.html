How it works

The item’s private details never go on the blockchain. Only a hash (a fingerprint) of a secret detail does.

01 · OWNERReport itType a secret only you know. Only its hash is stored.
02 · FINDERHand it inThe finder hands it to the desk and gets recorded.
03 · DESKConfirm foundThe desk confirms it has the item.
04 · OWNERClaim itType the same secret. The contract checks the hash.
05 · DESKMark returnedThe desk closes the case after handing it over.

About the demo accounts

These four accounts are built into the page so nobody has to install anything. Everyone who opens the link shares them. The roles behave exactly like switching accounts in Remix.

  • They only hold free Sepolia test ETH. Never send real ETH to them: their keys are inside this page, so anyone could use them.
  • Only the Desk needs funding from the faucet. Before another role acts, the page tops it up from the Desk automatically.
  • If the Desk runs low, the page shows a warning. Request more from the faucet the same way.

Data lives on the Sepolia test network, so it stays saved even when this page, Remix or the laptop is closed.
